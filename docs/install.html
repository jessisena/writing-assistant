Getting started

Writing Assistant Setup

Install the app as a native macOS window, understand its channels, and get comfortable with the day-to-day workflow.

Before you begin

  • claude CLI installed and authenticated — run claude --version in a terminal to confirm
  • uv installed and on your PATH — run command -v uv to confirm

Install

Run these once, in order. Everything after this is just clicking a dock icon.

1

Sync dependencies

From the project directory:

uv sync
2

Generate icons

Creates the PNG icons and the .icns file the launcher needs. Pillow is fetched temporarily — it's not added to the project.

uv run --with pillow python scripts/make_icons.py
3

Build the launcher app

Compiles an AppleScript bundle to ~/Applications/Writing Assistant.app and copies the icon in.

bash scripts/build_launcher.sh
4

Pin the launcher to your Dock

Open ~/Applications in Finder, find Writing Assistant, and drag it to the Dock. That's your entry point from now on.

Day-to-day use

Click the Dock icon. A native macOS window opens — the server starts automatically in the same process (expect 2–4 seconds on a cold start). From there:

1

Paste your text

Drop in a Slack draft, a paragraph you wrote in Spanish, a set of bullet points you want to tighten — anything. The tool handles multiple languages; non-English input gets translated first, then polished.

2

Pick a channel

The channel tells the model what the output will be used for. See the full breakdown in the next section.

3

Process

Click Process or press ⌘↵. A typical request takes 10–25 seconds.

4

Copy and use

The Polished Text card shows the result. Hit Copy to send it to your clipboard. If you wrote in English, the English Learning Summary below it explains what changed and why.

Channels

Each channel applies a different formatting and tone profile. Pick the one that matches where the text is going.

Slack message

Concise and scannable. Professional but not stiff. Short paragraphs, no heavy formatting.

Informal Slack

Peer-to-peer warmth. Contractions fine, emoji welcome where they carry tone. Gets straight to the point.

Talking points

Spoken bullet format for syncs or meetings. Each point lands on its own; no full paragraphs.

Formal document

Full prose with section headers. Appropriate for design docs, proposals, or written reviews.

AI prompt

Imperative and precise. Removes ambiguity, adds context — makes prompts more likely to work first time.

Other / general

Preserves the original structure. Fixes grammar, flow, and word choice without changing the format.

Server lifecycle

The server manages itself. You don't need to remember to start or stop it.

Dock click Server and window start together in one process. Cold start is 2–4 seconds.
Window closed Server stops immediately. Nothing lingers.
Manual stop Press ⌘Q to close the window and stop the server.
Logs tail -f ~/Library/Logs/writing-assistant.log

Troubleshooting

  • "claude CLI not found" banner in the app

    The server started but can't find the claude binary on the PATH the launcher uses. Check ls -la ~/.local/bin/claude. If it's installed elsewhere, update the PATH line in scripts/launcher.applescript and rebuild with bash scripts/build_launcher.sh.

  • "claude CLI failed" after a reboot

    The CLI's OAuth session may need refreshing. Run claude --version in a terminal — it will re-authenticate interactively. Then click the launcher again.

  • The launcher opens but the window shows a connection error

    The server crashed on startup. Check the log: tail -30 ~/Library/Logs/writing-assistant.log. You can also run uv run python -m assistant.desktop in a terminal to see the error inline.

  • Requests consistently time out

    The server waits up to 120 seconds for a Claude response. If it times out regularly, check your Claude subscription status — it can happen under heavy load. Trying again usually works.
